# Decisions

Record decisions that affect another contributor. Keep entries concise; link the task or PR for detail. Coordinate edits to this shared file.

## YYYY-MM-DD — Decision title

- **Status:** Proposed / accepted / superseded
- **Context:** What problem needs a decision?
- **Decision:** What did we choose, and why?
- **Consequences:** What changes for other contributors?
- **Owner and reference:** Person, issue, or PR
